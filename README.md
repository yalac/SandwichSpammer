# SandwichSpamer

Petit projet réalisé en C# dans le cadre de mon BTS informatique.

Cette application multiplateforme (.NET MAUI) est un prototype de jeu de type clicker où le joueur génère des sandwichs.

## Fonctionnalités

- Génération de sandwichs au clic.
- Affichage du compteur en temps réel.
- Interface graphique compatible bureau et mobile.

## Technologies

- C#
- .NET MAUI

## Prérequis

- SDK .NET (version 8 ou supérieure).
- Charge de travail **.NET MAUI** installée (via Visual Studio Installer ou en ligne de commande avec `dotnet workload install maui`).

## Installation et lancement

```bash
git clone https://github.com/yalac/SandwichSpammer.git
cd SandwichSpammer
```

```bash
dotnet restore
```

```bash
dotnet run --project SandwichSpammer/SandwichSpammer.csproj
```
